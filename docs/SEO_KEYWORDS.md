# Search terms and page targets

The site targets people looking for machinery, tools, parts and related service in Nepal, with Pokhara and Gandaki as the local focus. These are intent-based targets from the current catalog and service pages; no search-volume or ranking estimates have been verified.

| Page | Main search intent |
| --- | --- |
| Home | machinery supplier Pokhara; machinery and tools Nepal |
| `/products` | buy machinery online Nepal; power tools Nepal; agricultural machinery Nepal; machinery spare parts Nepal |
| Product pages | product name and model + price, specs or availability in Nepal |
| `/services` | machine repair Pokhara; machinery maintenance; machinery installation support |
| `/brands/deli` | Deli tools distributor Gandaki; Deli tools Nepal |
| `/location` | machinery shop Pokhara; machinery tools Baglung Buspark |

Use the normal spellings **machine**, **machinery**, and **online** in useful page copy and product names. Avoid adding misspellings such as “mechin” or unnatural phrases such as “online machine” as keyword lists; the live pages should read naturally and accurately describe available products and services. These terms belong in relevant titles, headings, product names and page copy; Google does not use the `meta keywords` tag for indexing or ranking.

For verified demand and competition, connect Ahrefs and review Google Search Console after the domain is live and verified. Revisit these targets using actual impressions, clicks and customer enquiries. Google recommends distinct page titles and useful descriptions, and crawlable links between ecommerce categories and product pages: [title links](https://developers.google.com/search/docs/appearance/title-link), [snippets](https://developers.google.com/search/docs/appearance/snippet), [ecommerce site structure](https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure).
